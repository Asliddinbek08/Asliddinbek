# Startup Hub

O‘zbekiston startaplari uchun profil, rivojlanish tarixi va investorlar bilan tanishuv interfeysi.

## Ishga tushirish

Bu oddiy HTML, CSS va JavaScript sayt. Kutubxonalar o‘rnatish yoki build qilish shart emas. `index.html`, `style.css` va `app.js` bir katalogda turadi. Mahalliy HTTP server orqali ko‘rish mumkin.

## Vercel

GitHub repositoriyasini import qiling. Framework: Other. Root Directory: repozitoriya ildizi. Build Command: bo‘sh. Output Directory: `.`. `vercel.json` shu sozlamalarni belgilaydi. Main tarmog‘idagi o‘zgarishlarni Vercel avtomatik nashr qilishi uchun GitHub integratsiyasini ulang.

## Hozirgi imkoniyatlar

- Startap katalogi, qidirish va soha filtri.
- Startap profilini yaratish va saqlash.
- Yangilanish, so‘nggi versiya va faoliyat kalendari.
- Investor bilan tanishuv so‘rovi namunasi.
- Debocha uchun namuna amaliy rejalar va asl platformaga havola.
- Patentga tayyorgarlik yo‘riqnomasi.

Bu frontend prototipi. Yangi profillar, saqlanganlar va qaydlar faqat joriy brauzerning localStorage xotirasida saqlanadi. Boshqa domen yoki brauzerga avtomatik ko‘chmaydi. Birinchi uchta startap va barcha investorlar xayoliy namunalardir.
